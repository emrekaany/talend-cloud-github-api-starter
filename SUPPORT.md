# Support

## Fastest path

1. Run `talend-api-starter demo`.
2. Read [Troubleshooting](docs/troubleshooting.md).
3. Search existing issues and Discussions.
4. If the problem is reproducible with synthetic data, open the appropriate issue form.

Community support is best effort. There is no guaranteed response time, compatibility commitment, provider escalation, or production SLA for the free starter.

## Public channels

| Need | Channel |
| --- | --- |
| Reproducible bug using bundled/synthetic data | Bug report issue form |
| Documentation correction | Documentation issue form |
| Read-only feature idea | Feature request issue form |
| General non-sensitive usage question | [GitHub Discussions](https://github.com/emrekaany/talend-cloud-github-api-starter/discussions) |
| Vulnerability | Private route in [SECURITY.md](SECURITY.md) |
| Private semantic diff, dependency, migration, data-quality, or deployment work | [Assistant for Talend](docs/services.md) |

## Never post publicly

Do not put these in an issue, Discussion, pull request, gist, screenshot, or link:

- token, password, cookie, authorization header, SSH key, or environment dump;
- client/employer file, log, report, screenshot, database content, or source archive;
- private repository/clone URL or private Git reference;
- live tenant, workspace, project, artifact, task, run, user, or account ID;
- real `.item`, `.properties`, `talend.project`, context, connection, SQL, generated Java, or job content;
- personal, customer, employee, contract, incident, or production information.

Redacting a real client file does not make it acceptable for a public issue. Create a new synthetic reproduction.

## What public maintainers can help with

- installation and CLI behavior for supported Python versions;
- offline demo failures;
- bounded public-GitHub workflow using non-sensitive repositories;
- documented Talend Cloud configuration and safe error categories;
- documentation, synthetic fixtures, and read-only feature proposals.

## What public maintainers cannot provide

- Talend Cloud accounts, trials, licenses, roles, PATs, or endpoint access;
- GitHub account recovery or rate-limit exceptions;
- access to private repositories or enterprise networks;
- diagnosis from client source, live logs, credentials, or production data;
- official Qlik/Talend support or warranty;
- emergency production operations.

For provider-specific account or product issues, use the provider's official support channel. This independent project is not affiliated with, sponsored by, or endorsed by Qlik.
